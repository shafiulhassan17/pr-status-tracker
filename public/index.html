✓ Local Database Active with Excel Sync: Currently tracking all PRs and POs from your Excel files (CEPL and SPPL loaded). You can connect to your enterprise SQL server (Microsoft SQL Server, MySQL, or PostgreSQL) at any time below.
Enterprise SQL Server View Script (For your Database Administrator): 
-- Run on your external SQL Server to create the standard procurement tracking view:
CREATE OR ALTER VIEW vw_PrPoTracking AS
SELECT 
    pr.DATAAREAID     AS plant,
    pr.REQNUMBER      AS pr_number,
    po.PURCHID        AS po_number,
    po.ORDERACCOUNT   AS vendor_account,
    v.NAME            AS vendor_name,
    pol.LINENUM       AS line_number,
    pol.ITEMID        AS item_id,
    pol.NAME          AS item_name,
    pol.PURCHUNIT     AS unit,
    pol.INVENTSITEID  AS site,
    pol.INVENTLOCATIONID AS warehouse,
    pol.PURCHSTATUS   AS po_status,
    pol.QTYORDERED    AS purch_qty,
    pol.QTYRECEIVED   AS received_qty,
    pol.PURCHPRICE    AS purchase_price,
    po.CREATEDDATETIME AS po_create_date,
    pol.DELIVERYDATE  AS expected_dlv_date
FROM PurchLine pol
LEFT JOIN PurchTable po ON pol.PURCHID = po.PURCHID
LEFT JOIN VendTable v ON po.ORDERACCOUNT = v.ACCOUNTNUM
LEFT JOIN PurchReqLine pr ON pol.PURCHREQLINEREFID = pr.RECID;
